Everything here works offline. The game has no accounts, no servers and no network code at all, so "it cannot connect" is never the problem: if the window is up, the game is running.

1. Getting help

Report a problem as an issue on this site's repository: github.com/chanliu1983/oceanstory-site/issues. Issues may be written in English or Chinese. Please say what you were doing, what you expected, and what happened instead — and if it is a visual problem, attach a screenshot or a short screen recording. A screen recording is easy to make: press Shift + Cmd + 5 and pick a window.

2. Requirements

macOS13.0 or later (Ventura)
ProcessorApple silicon and Intel, both
DiskAbout 300 MB
NetworkNot required, and not used
GamepadOptional. Any standard Bluetooth or USB controller

If the game will not open at all, open the Console app and launch it from there, or run it from a terminal: /Applications/Oceanstory.app/Contents/MacOS/Oceanstory --quit-after 900 The output tells you what went wrong. A Mac that is not connected to the internet is not the cause of a failure to start.

4. Interface language

English and Chinese both ship in the same build. Switch at any time from the main menu (Options), or from the pause menu while you are sailing. The choice is remembered.

5. Your saves

Saves live in the game's own folder inside your user data directory, and nowhere else:

  • ~/Library/Application Support/Godot/app_userdata/Oceanstory- Spice Empire/ — the Mac App Store build writes to ~/Library/Containers/com.lei.oceanstory.mas/ instead, which is the same idea in a sandboxed container.

Inside it you will find spice_slot_0.json to spice_slot_9.json (the ten runs), season_meta.json (what carries over between seasons) and ui_settings.cfg (your language and graphics settings). Copy that folder to back your runs up. Uninstalling the game removes them.

There are ten slots, each on its own map. A new voyage retires the run you were playing; the progress that survives a season stays.

6. Common questions

“The ship is too slow to get anywhere.”

Weight is the reason. Fresh water and food are heavy, and a hold full of them is a slow ship. Carry what the trip needs, not a season's worth. The ship panel (V) shows the weight you are carrying and what it is costing you in knots.

“I keep running out of food.”

You need grain as well as salt meat — five days of nothing but meat and the crew starts to fail, and a failing crew sails slowly and dies quickly. A contract's route tells you the days at sea before you accept it; the yard sells the provisions for exactly that trip.

“My cannon will not fire.”

The guns only fire at a marked target. Put the cursor on a hostile ship and press the mark key, then hold the fire key to charge. Each side reloads on its own, so a broadside takes four seconds a gun.

“The port is closed.”

Sometimes it is quarantine, sometimes it is a blockade in a war between two powers, and sometimes it is simply that the port does not trade. The captain's log says which, and the chart shows the war line.

“I lost my run.”

Check the other nine slots first — each is a separate run on a separate map. If the file is gone, it was deleted with the game.

7. Known issues

  • On some Macs the first launch takes a few seconds longer while the shaders are compiled. It only happens once.
  • A gamepad connected while the game is running is picked up on the next screen change, not instantly.
  • On a display larger than 2880×1800 the interface is scaled up rather than cropped, so no text is lost.

5. 存档在哪

存档只在这个游戏自己的文件夹里，别的地方没有：

  • ~/Library/Application Support/Godot/app_userdata/Oceanstory- Spice Empire/ ——Mac App Store 版会写在 ~/Library/Containers/com.lei.oceanstory.mas/ 里，原理一样，只是被沙盒收着。

里面是 spice_slot_0.json 到 spice_slot_9.json（十个档）、 season_meta.json（跨季保留的东西）和 ui_settings.cfg（语言与画面设置）。 想备份就把这个文件夹复制走；卸载游戏会一起删掉。

十个档各自一张地图。开新航程会结束你正在玩的那一局，跨季保留的进度不会丢。

6. 常见问题

「船太慢，到不了。」

因为重量。淡水和粮食很重，满舱就是慢船。带上这趟需要的量，不要带一整季的量。 船面板（V）上写着当前载重，以及它让你损失了多少节。

「老是缺粮。」

光吃咸肉不行——连续五天只有肉，船员就开始垮，垮了的船更慢，死得更快。 契约卡上的航线会写清楚要跑几天，接之前先看；船厂里卖的补给刚好够这一趟。

「炮打不出去。」

炮只会打被标记的目标。把光标移到敌船上按标记键，再按住开炮键蓄力。 左右两舷分别装填，一轮齐射每门炮要四秒。

「港口进不去。」

有时是检疫，有时是两个势力开战设的封锁，有时是这个港本身不贸易。 船长日志会写原因，海图上也能看到那条战争线。

「我这一局没了。」

先看看另外九个档——每一档都是独立的航程、独立的地图。 如果文件真的不在了，那它是被你删掉的，或者随游戏一起卸载了。
