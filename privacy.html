Privacy Policy

Oceanstory · Spice Empire · © 2026 Lei Liu

Oceanstory does not collect, store, transmit or sell any personal data. The game never opens a network connection. There are no accounts to create, no email address to give, and nothing is sent to the developer — or anywhere else.

No accounts No network No analytics No advertising No in-app purchases No crash reporting

1. Summary

Oceanstory runs entirely on your own computer, offline. It has no sign-in, no user accounts, no advertising SDKs, no analytics or telemetry library, and no crash or error reporting. It contains no in-app purchases. The build contains no third-party plugins at all.

You do not have to take this page's word for it either. The build ships with no networking code and no third-party plugins at all: there is no request, no socket and no tracker in it to switch off.

2. What is stored on your device

The game writes a small number of files to your own user data folder, in the place the operating system gives every app. They stay on your computer, are readable only by the game, and are never uploaded:

  • Settings — ui_settings.cfg: your interface language and your graphics settings.
  • Save slots — spice_slot_0.json through spice_slot_9.json: the ten runs you can keep, each with its own map, sea, towns, prices, cargo and calendar. A single older file, spice_world.json, may also be present as a leftover from an earlier version.
  • Campaign progress — season_meta.json: the things that survive a season, such as blueprint parts, what they unlocked and which seasons you have played.
  • Event cards — events.json: optional event cards you or a tool have added. The game ships with its own card set and does not need this file.

Deleting the game removes them. There is no other local storage, no cookie, and no identifier of any kind.

3. Network connections

None. The game contains no networking code at all: no HTTP requests, no sockets, no multiplayer, no update check, no crash upload. If you play it with the network switched off, every feature still works.

The only thing that ever reaches the network is what you type into a browser, and that is not the game.

4. Third parties

No analytics, advertising, attribution, crash-reporting or telemetry SDK is included in the build, and the project pulls in no third-party plugin. The game contacts no third party, because it contacts nobody.

5. Children

The game is suitable for all ages. It contains no blood, no nudity, no user-generated content, no advertising and no in-app purchases, and it collects no data, so it does not knowingly collect any personal information from children.

6. Your rights and control

Because no data is collected, there is nothing for the developer to access, correct, export or delete on your behalf. You have complete control: everything the game stores is a file in your own folder, and deleting the game, or deleting that folder, removes it permanently.

7. Changes to this policy

If a future version changes what the game transmits or stores, this page will be updated before that version ships, and the effective date below will change. Given the game has no networking code at all, that would be a significant change, and this page would say so before the build that contains it.

8. Contact

Questions about this policy, or anything else about the game, can be raised as an issue on this site's repository: github.com/chanliu1983/oceanstory-site/issues. Issues may be written in English or Chinese.

1. 摘要

游戏完全在你的电脑上离线运行。没有登录，没有用户账号，没有广告 SDK，没有统计或遥测库， 也没有崩溃或错误上报。游戏不含内购，构建版本里没有任何第三方插件。

你也不必只信这一页：构建版本里一行联网代码、一个第三方插件都没有—— 没有请求、没有 socket、没有统计脚本，也就没有"关掉"这回事。

2. 存储在本机的数据

游戏只会在你自己的用户数据目录里写几个文件。都留在你的电脑上，只有游戏能读取，永远不会上传：

  • 设置——ui_settings.cfg：界面语言和画面设置。
  • 存档槽——spice_slot_0.json 到 spice_slot_9.json： 你留得下的十局，各自一张地图、那片海、那些城镇、那些价钱、货舱和日历。 另外可能还有一个旧版本留下的 spice_world.json 单档文件。
  • 战役进度——season_meta.json：跨季留存的东西， 比如蓝图零件、解锁了什么、玩过哪几季。
  • 事件卡——events.json：你或某个工具加入的可选事件卡。 游戏自带卡组，没有这个文件也能玩。

删除游戏即一并删除。除此之外没有别的本地存储，没有 Cookie，没有任何标识符。

3. 网络连接

没有。游戏里没有任何联网代码：没有 HTTP 请求、没有 socket、没有联机、 没有更新检查、没有崩溃上传。断网玩，所有功能照常。

唯一会走上网络的东西，是你自己在浏览器里敲的东西——而那不是游戏。

4. 第三方

构建版本中不包含任何统计、广告、归因、崩溃上报或遥测 SDK，项目也没有引入任何第三方插件。 游戏不联系任何第三方，因为它谁也不联系。

5. 儿童

本游戏适合全年龄。内容无血腥、无裸露、无用户生成内容、无广告、无内购。 由于不收集任何数据，本游戏不会有意收集儿童的个人信息。

6. 你的权利与控制

因为不收集任何数据，开发者手上没有任何可供访问、更正、导出或删除的内容。完全的控制权在你： 游戏存储的一切都是你自己目录下的文件，删除游戏或删除该目录即可彻底清除。

7. 政策变更

如果未来的版本改变了游戏的传输或存储内容，本页面会在该版本发布前更新，下方的生效日期也会随之改变。 鉴于游戏现在一行联网代码都没有，那会是一次很大的改动——而带它上线之前，这一页会先写清楚。
